# 结果观察数据约定

更新：2026-09-24。本文件说明本地新增的参数快照、摔落与斜坡观察协议；尚未部署服务器，不代表正式试验开放。最终目标与验收仍以[物理检查方案第 2.5 节](Newton–MuJoCo%203D%20资产物理合理性仿真检查方案.md)为准。

## 本步交付

- 新运行在确认资产内容哈希后，从该版本的组合 USD 读取参数快照，随 `manifest.json` 的 `asset.physics_parameters` 保存。
- 当前单刚体斜坡开发工况保存具有明确测量定义的沿坡位移；原字段保留以兼容已有使用方。
- 新摔落运行逐物理步采集整体碰撞几何净空，记录首次完整回弹高度/比例与整个时窗内最大穿透；接入 CPU 记录和 GPU 仿真/录像路径，服务器验证仍待完成。
- 结果索引向页面提供参数快照、观测状态、物理/录像时长和源码版本。页面展示最终覆盖缺口、参数依据、条件、量化值与录像观察提示。
- 只读浏览与重建索引不会回填或修改历史运行。既有摔落录像没有回弹/穿透采样，本步明确显示未测量。

## USD 输入参数快照

`physics_parameters.schema_version = 1`，`records` 按启用的碰撞形状记录：

| 字段 | 含义 |
| --- | --- |
| `field` | 精确 USD 字段名；当前含 solref、solimp、condim、priority、滑动/滚动摩擦 |
| `collision_prim` | 对应碰撞形状的 stage 内路径，不是服务器文件路径 |
| `value_prim` | 提供标注的形状或绑定物理材质 prim |
| `status` | `recorded`、`not_authored`、`material_unbound`、`time_varying` 或 `invalid` |
| `value` | 有限常量标注值；不可用时为 null，不猜引擎默认值 |
| `source` | 有标注时为 `authored_in_package`，其他情况为 `unknown` |

只记录已启用碰撞形状及其绑定物理材质，排除纯视觉形状；不同形状的不同值不取平均。标注位置可展开查看，主页面保留值和准确字段名。随时间变化的参数不能作为一个常量展示。

这里的“包内标注”不证明它是原始生产参数、现实测量值或已验证的引擎生效值。当前快照不解释转换报告或区分测试补充来源，明确标识 `provenance=package_authorship_only` 和 `solver_effective_values=not_recorded`；功能测试标志继续显示。求解器最终接触值、完整参考面条件与更精细来源链仍待采集，F05 尚未完成。

## 沿坡位移定义 v1

当前仅适用于已经限制为单刚体的本地斜坡开发工况。新增 `case.json.observations.along_slope_displacement`，`definition=single-body-origin-downhill-displacement-v1`：

```text
displacement = dot(final_body_origin - initial_body_origin, downhill_unit_vector)
```

- 测量对象为唯一刚体的坐标原点，**不是质心**，也不是整体资产包围盒中心。
- 位移单位为米；下坡为正，上坡为负。它是首末净位移，不是累计路程，不能据此自动判定滑动、滚动、翻倒或是否稳定。
- 坐标均为模型世界坐标。保留 `initial_position_m`、`final_position_m` 和 `direction_world`，方向必须为单位向量。
- 保存 `body_index=0`、`body_count=1`、`reference_point=body_frame_origin`、`sampling=initial_and_final_state`。
- 时窗从新场景 `0 s` 开始，到实际完成的 `scene.sim_time` 为止；保存 `start_time_seconds`、`end_time_seconds`。录像初始静止展示不计入测量时窗。
- 多刚体、非有限位置、非单位方向、非正时窗或非全新场景均拒绝套用此定义。未来多刚体斜坡须另定义整体测量对象，不静默取第一个刚体。
- 验证使用已知投影的合成坐标（含横向、法向移动、零值、负值）及记录器接线测试；数值一致性核对容差为相对 `1e-10`、绝对 `1e-12 m`。这是汇总算术的一致性容差，不是仿真精度保证或物理合格阈值。

结果索引在显示新记录前重新核对定义、单位、首末坐标投影及有效状态；不一致时标为无效，不回退到同一文件中的旧字段。此核对不改写原文件，也不证明物理模拟本身准确。

## 观察状态与旧记录

| 状态 | 显示含义 |
| --- | --- |
| `measured` | 定义和数据完整且一致；可显示有限值，包括零 |
| `legacy_record` | 保留旧版已记录的有限位移及配置时长；不补推测量点、方向和实际采样时窗 |
| `not_measured` | 没有采集该量，不等同于零 |
| `not_started` | 尚未运行 |
| `incomplete` | 运行中、失败或中断；本版不将剩余值作为完整结果展示 |
| `invalid` | 状态数值无效或测量记录不一致 |
| `unverified` | 斜坡记录没有明确的数值有效性结果 |
| `unsupported` | 当前场景不支持此测量定义，不回退到取景包围盒 |
| `not_observed` | 观察期内未触地，不能给出回弹高度 |
| `no_liftoff` | 触地后未观察到整体离地，不能用局部翘起代替回弹 |

新页面兼容旧结果索引：有明确数值有效性记录时保留旧沿坡位移，并说明测量口径未记录；没有参数快照则显示未记录，不读取当前资产补填过去。旧移动分类标签仅留在技术详情，不作为主页面物理结论。

## 摔落净空与首次回弹定义 v1

`case.json.observations` 保存 `first_rebound_height`、`first_rebound_ratio` 和 `maximum_ground_penetration`，定义版本为 `whole-asset-plane-clearance-first-flight-v1`。

1. 测量对象是编译后模型中全部参与碰撞的资产形状，包括多刚体资产各部分；排除纯视觉形状和地面。以一个静态、水平、Z 朝上的地面平面为基准，净空 `c(t)` 为整体最低碰撞点的世界 Z 减去地面 Z。
2. 从初始状态 `t=0` 开始，每个完成的物理步读取 Newton 刚体位姿。几何来自 MuJoCo 编译模型，避免读取积分前的旧几何世界变换。记录采样间隔、数量、实际时窗和定义版本；缺样、错序、非有限值或初始净空不大于事件容差均无效。
3. 事件容差固定为 `ε=1e-5 m`（0.01 毫米）：首次 `c≤ε` 记为触地；之后首次 `c>ε` 为整体离地，再次 `c≤ε` 为落地。它是采样事件分类容差，不是材料参数、接触力判据或物理质量合格阈值。
4. 首次回弹高度为该第一次完整离地段的最大采样净空；必须观察到再次落地才给出最终值。未触地、触地后未整体离地、观察末尾仍在第一次飞行中分别记录 `not_observed`、`no_liftoff`、`incomplete`，数值为 null，不填零。后续更高反弹不改变首次回弹值。
5. 高度比例以**初始实际测得净空**为分母，与回弹保持同一碰撞几何口径。原有释放放置仍采用取景边界，本步不修改场景行为；页面并列显示配置净空与实测净空，不能把两者当作必然相等。
6. 最大地面穿透为整个物理观察时窗内 `max(0, -c(t))`，包括后续碰撞和下沉，不限于首次碰撞。完整采样且无穿透时允许测得零；零值不显示“穿透发生时刻”。记录最大值对应采样时刻。

支持球、盒、椭球、胶囊、圆柱的解析支撑面以及编译后的网格碰撞支撑顶点；网格处理编译缩放、重心化、旋转及简化凸包。当前适配固定依赖版本 Newton 1.4 / MuJoCo 3.10 / MuJoCo Warp 3.10。没有加入接触 margin/gap，也没有用视觉网格或相机包围盒替代。额外静态碰撞物、倾斜地面、显式接触对、可变形体、排除地面碰撞的资产形状或不支持的形状均明确标记不支持。

数值是**采样点的几何极值**，不保证捕获两个物理步之间的瞬时峰值。几何支撑点对照 MuJoCo 距离查询、已知旋转/缩放解析结果及合成事件序列进行检查；误差断言是算法一致性检查，不是仿真精度保证。当前不插值、不推断停止时间，不据此自动判定资产质量。求解器数值误差、实际 GPU 采样、步长收敛与漏掉短暂接触事件的风险仍须后续验证，F06 尚未关闭。

`drop_measurement` 保留几何/位姿来源、地面和资产形状 ID、初始化与采样耗时、不支持原因。几何诊断当前通过 CPU NumPy 只读计算，GPU 路径每步回传刚体位姿；不推进或修改物理状态，不改变 GPU 物理解算/渲染设备。已做本地几何开销检查，**服务器 GPU 回传开销尚未测量**，不能将本地耗时当作 GPU 性能结论。

结果索引重新校验测量版本、单位、窗口/步数、事件顺序、数值状态和比例一致性；失败或未完成的运行不显示完整测量值，旧结果不回填。实现依据包含固定版本依赖源码，以及 MuJoCo 官方[网格编译说明](https://mujoco.readthedocs.io/en/stable/XMLreference.html#asset-mesh)和[仿真状态更新说明](https://mujoco.readthedocs.io/en/stable/programming/simulation.html)。

## 尚未完成

真实 GPU 运行的测量值、同步开销与录像对照仍需验证；接触参数实际生效值和来源细分尚待实现。已有 Artiverse 录像没有新测量，不能从录像或旧初末取景边界补算本协议数据。
