# Newton–MuJoCo 3D 资产物理合理性仿真检查方案

本报告说明如何仅依靠物理仿真，对[Newton 3D 资产表示](https://ucn5dbbacid6.feishu.cn/wiki/WA0twg8A6i7evgkS27lczNKCnce?from=from_copylink)2\.6 Final（最终字段表）中的参数进行统一检查。

这里的“物理合理”是指：参数之间没有物理矛盾，与资产几何和尺度基本一致，并能产生**符合直觉**的运动。仿真可以发现明显错误，但不能在没有实物测量的情况下证明参数就是现实真值。

## 1\. 字段与检查方法

## 2\. 具体检查方法

### 2\.1 浸水测试

统一将物体浸入水中，观察物体的下沉、浮起速度等（仅直观查看效果）。

参考资料：https://physx\-omni\.github\.io/

这个试验我们目前认为并不是很必要做，且实现上还有待探究的技术问题，故应当优先考虑完成后两个试验。

### 2\.2 固定斜坡摩擦试验

**关于摩擦：现实中的摩擦情况十分复杂，两种材料间的摩擦并不能仅通过两种材料各自的参数计算得出，如果需要更细致的模拟则需要建立 n*n 的材料对，实现起来过于复杂，目前有几篇论文：[Generalizable Friction Coefficient Estimation via Material Embedding and Proxy Interaction Modeling](https://arxiv.org/abs/2604.24188)、[Probabilistic Surface Friction Estimation Based on Visual and Haptic Measurements](https://arxiv.org/abs/2010.08277)等，是由少量数据进行对摩擦的预测的。这里我们只给每个单独资产一个摩擦数值进行模拟**

因此，本试验只能比较各资产在相同条件下的相对运动表现，不能证明该数值适用于任意地面或夹爪材料。相关研究见第 3 节。

试验使用统一的中性参考面。参考面不表达木板、金属等具体材质，也不改变资产的待测摩擦值。

1. 预先确定一组固定坡度，包含缓坡、中等坡和陡坡。

2. 在每个坡度上依次测试全部资产。待测资产始终使用其已标注的摩擦参数，不根据试验结果调整参数。

3. 所有资产采用相同的释放方式（赋予初速度等），并尽量使用一致的初始姿态。坡道角度保持不变，坡道的长宽可以随资产尺寸成比例调整，使大小不同的资产都有足够的运动空间。

4. 观察资产是否开始运动、主要以滑动还是滚动或翻倒、运动距离和停止过程，并与同一坡度下的其他资产及标准参照物比较。

5. 在水平面补充一次滑行观察，比较各资产离开斜坡后的减速和停止表现，可以以此观察物体滚动摩擦相关的参数。

本试验用于判断：

- 某资产是否相对其他资产明显过滑或过黏；

- 同一资产在坡度增大后是否表现出合理的运动趋势；

- 资产的滑动、滚动或翻倒方式是否与其外形和现实直觉大致一致。

### 2\.3 摔落试验

MuJoCo 允许接触面发生很小的数值穿透，以获得稳定的接触力。`solref` 和 `solimp` 控制这种接触的恢复速度、阻尼和约束强度；它们不能直接当作现实材料常数。

试验使用统一的刚性水平参考面。

1. 为每个资产设置低、中、高三档相对释放高度，具体高度随资产尺寸成比例调整。资产从静止状态自由落下。

2. 在同一场景中放置用于直观对比物体大小、高度的标准参考物，并设置清晰的高度标记，帮助观察者判断下落和回弹的尺度。

3. 观察首次碰撞时的回弹高度、碰撞后的翻滚方式，以及是否出现明显穿入地面、突然弹飞等异常。

4. 继续观察资产能否自然停止，是否持续抖动、反复弹跳、缓慢下沉或无法稳定接触。

5. 对所有资产重复三档高度。释放高度增大时，碰撞表现应当连续变化，不应突然出现与现实直觉明显不符的运动。

本试验用于发现接触过软、过硬、回弹或阻尼明显异常，以及接触不稳定等问题。`solref` 和 `solimp` 会共同影响结果，因此这里只判断两者组合后的整体表现，不分别推断某个字段的真实值。

## 3\. 摩擦数值的限制与研究方向

### 3\.1 当前方案的限制

现实中的滑动和滚动摩擦都取决于两个接触表面，以及粗糙度、载荷、速度、温度、磨损和润滑状态。MuJoCo 必须从两个碰撞体的字段得到一个最终值；同优先级时通常取两侧摩擦参数中较大的值。这是仿真计算规则，不是现实材料定律。

因此，本方案中的摩擦试验只能用于：

- 发现资产默认摩擦值导致的明显过滑、过黏或滚动异常；
- 为人工检查提供统一、直观的比较场景；
- 作为没有更具体接触数据时的粗略检查。

它不能用于：

- 推断资产与所有其他材料接触时的真实摩擦；
- 精确预测不同材质夹爪所需的夹持力；
- 替代真实材料接触试验。

### 3\.2 相关论文

- [Generalizable Friction Coefficient Estimation via Material Embedding and Proxy Interaction Modeling](https://arxiv.org/abs/2604.24188)：最直接针对任意材料组合问题。它让每种材料只与少量代理材料进行测试，再学习预测任意两种材料的摩擦，将测试数量从两两组合降低为与材料数量近似线性增长。目前是 2026 年 arXiv 预印本，仍需要代理材料测量和模型训练，适合作为后续研究方向。
- [Probabilistic Surface Friction Estimation Based on Visual and Haptic Measurements](https://arxiv.org/abs/2010.08277)：结合视觉和少量机器人触觉探索，估计多材料物体表面的摩擦分布。它可以减少逐点测试，但仍需要真实接触数据。
- [In-Hand Object-Dynamics Inference using Tactile Fingertips](https://arxiv.org/abs/2003.13165)：让机器人逐渐减小夹持力直到发生滑移，通过触觉测量估计夹爪与物体之间的实际摩擦，适合后续抓取场景。
- [Online Friction Coefficient Identification for Legged Robots on Slippery Terrain Using Smoothed Contact Gradients](https://arxiv.org/abs/2502.16843)：根据机器人运动和接触结果在线反推当前接触的摩擦系数，说明摩擦可以在实际交互中识别，而不必完全依赖资产预标注。
- [Friction from Vision](https://www.martimbrandao.com/papers/Brandao2016-humanoids-friction.pdf)：研究根据图像、材质类别和文字资料预测机器人接触摩擦，同时表明仅凭人眼判断摩擦存在明显不确定性。

当前报告不采用上述复杂方法，只保留“资产默认摩擦值的直观筛查”。如果未来需要提高夹爪接触精度，可以优先研究代理材料方法或基于滑移的在线识别。
