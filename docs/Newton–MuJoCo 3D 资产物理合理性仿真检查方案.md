# Newton–MuJoCo 3D 资产物理合理性仿真检查方案

需求复核（2026-09-24）：本轮依据用户重新提供的最初任务文档恢复项目目标，并补充第 2.4 节结果展示需求。本文是物理检查需求与设计方案，不是当前功能清单或实验结论。Artiverse 单个剪刀派生样本已完成 GPU 摔落录像和人工播放确认，仅作代码功能测试；正式多高度、坡度批次尚未开放，见 [当前状态](../deployment/CURRENT_STATUS.md)。尚待访谈确认的范围单独列出，不视为已批准。

本报告说明如何仅依靠物理仿真，对[Newton 3D 资产表示](https://ucn5dbbacid6.feishu.cn/wiki/WA0twg8A6i7evgkS27lczNKCnce?from=from_copylink)2\.6 Final（最终字段表）中的参数进行统一检查。

这里的“物理合理”是指：参数之间没有物理矛盾，与资产几何和尺度基本一致，并能产生**符合直觉**的运动。仿真可以发现明显错误，但不能在没有实物测量的情况下证明参数就是现实真值。

## 2\. 具体检查方法

### 2\.1 浸水测试

统一将物体浸入水中，观察物体的下沉、浮起速度等（仅直观查看效果）。

参考资料：https://physx\-omni\.github\.io/

这个试验我们目前认为并不是很必要做，且实现上还有待探究的技术问题，故应当优先考虑完成后两个试验。

### 2\.2 固定斜坡摩擦试验

**关于摩擦：现实中的摩擦情况十分复杂，两种材料间的摩擦并不能仅通过两种材料各自的参数计算得出，如果需要更细致的模拟则需要建立 n*n 的材料对，实现起来过于复杂，目前有几篇论文：[Generalizable Friction Coefficient Estimation via Material Embedding and Proxy Interaction Modeling](https://arxiv.org/abs/2604.24188)、[Probabilistic Surface Friction Estimation Based on Visual and Haptic Measurements](https://arxiv.org/abs/2010.08277)等，是由少量数据进行对摩擦的预测的。这里我们只给每个单独资产一个摩擦数值进行模拟**

因此，本试验只能比较各资产在相同条件下的相对运动表现，不能证明该数值适用于任意地面或夹爪材料。相关研究见第 3 节。

试验使用统一的中性参考面。参考面不表达木板、金属等具体材质，也不改变资产的待测摩擦值。

1. 预先确定一组固定坡度，包含缓坡、中等坡和陡坡。

2. 在每个坡度上依次测试全部资产。待测资产始终使用其已标注的摩擦参数，不根据试验结果调整参数。

3. 所有资产采用相同的释放方式（赋予初速度等），并尽量使用一致的初始姿态。坡道角度保持不变，坡道的长宽可以随资产尺寸成比例调整，使大小不同的资产都有足够的运动空间。

4. 观察资产是否开始运动、主要以滑动还是滚动或翻倒、运动距离和停止过程，并与同一坡度下的其他资产及标准参照物比较。

5. 在水平面补充一次滑行观察，比较各资产离开斜坡后的减速和停止表现，可以以此观察物体滚动摩擦相关的参数。

本试验用于判断：

- 某资产是否相对其他资产明显过滑或过黏；

- 同一资产在坡度增大后是否表现出合理的运动趋势；

- 资产的滑动、滚动或翻倒方式是否与其外形和现实直觉大致一致。

### 2\.3 摔落试验

MuJoCo 允许接触面发生很小的数值穿透，以获得稳定的接触力。`solref` 和 `solimp` 控制这种接触的恢复速度、阻尼和约束强度；它们不能直接当作现实材料常数。

试验使用统一的刚性水平参考面。

1. 为每个资产设置低、中、高三档相对释放高度，具体高度随资产尺寸成比例调整。资产从静止状态自由落下。

2. 在同一场景中放置用于直观对比物体大小、高度的标准参考物，并设置清晰的高度标记，帮助观察者判断下落和回弹的尺度。

3. 观察首次碰撞时的回弹高度、碰撞后的翻滚方式，以及是否出现明显穿入地面、突然弹飞等异常。

4. 继续观察资产能否自然停止，是否持续抖动、反复弹跳、缓慢下沉或无法稳定接触。

5. 对所有资产重复三档高度。释放高度增大时，碰撞表现应当连续变化，不应突然出现与现实直觉明显不符的运动。

本试验用于发现接触过软、过硬、回弹或阻尼明显异常，以及接触不稳定等问题。`solref` 和 `solimp` 会共同影响结果，因此这里只判断两者组合后的整体表现，不分别推断某个字段的真实值。

### 2.4 结果展示必须服务于物理合理性检查

#### 2.4.1 目标与信息优先级

结果页必须帮助检查者回答：**这个资产使用什么参数，在什么统一条件下表现怎样，哪些现象需要复查，以及还有哪些试验或证据缺失。**“运行成功”“生成录像”只证明执行与产物链路完成，不能单独作为项目交付完成或资产合理性的判断依据。

本轮首先恢复最初方案已明确的观察需求；不能把“正式检查尚未实现”转化为永久只做程序功能验证。当前 Artiverse 样本的功能测试属性也不能替代整个项目的最终目标。

页面应按以下次序组织信息：

1. **检查对象和覆盖范围**：资产名称、来源、可区分的版本标记；本次检查类别；各档高度或坡度哪些已完成、失败、尚未做。不把未运行项隐藏成不存在。
2. **本次要检查什么**：摔落检查接触恢复和稳定表现；斜坡检查默认摩擦导致的相对运动表现。直接列出需要观察的现象，不要求用户先理解内部 profile 名称。
3. **影响解释的参数与条件**：待检查的资产参数、它们的来源、参考面条件、释放方式、初始姿态、实际高度/坡度、尺度和观察时长。已标注值、测试临时补充值、引擎默认值和求解器实际采用值须区分；未记录的内容明确标为未记录，不从字段名或当前环境猜补。
4. **观察证据和比较**：录像、清楚的尺寸/高度参照，以及原方案要求的同一资产多工况、同一坡度下不同资产与标准参照物的比较。比较前展示版本、释放和参考条件的差异，不把不同试验条件解释为资产差异。
5. **技术追溯**：完整哈希、运行编号、源码版本、求解器配置、设备与日志可折叠，但不能把待检查的物理参数和理解试验所需的条件一并藏起来。

#### 2.4.2 两类试验的必要观察内容

| 试验 | 必须让检查者能够观察或比较的内容 | 应直接可见的参数与条件 | 不允许替代为 |
| --- | --- | --- | --- |
| 摔落 | 首次碰撞回弹、碰撞后翻滚、穿透或弹飞；持续抖动、反复弹跳、缓慢下沉；是否在观察期内趋于稳定；低中高三档的变化趋势 | `mjc:solref` 与 `mjc:solimp` 组合、参数来源、参考面；资产尺度、相对高度档位及实际净空、初始姿态与速度、物理观察时长 | 仅显示“完成”、最终一张截图、单个中档短片或 GPU 型号 |
| 斜坡与水平滑行 | 是否开始运动；主要滑动、滚动还是翻倒；运动距离、减速与停止过程；同坡度下相对过滑/过黏、坡度增大后的趋势 | `physics:dynamicFriction`、`mjc:rollingfriction`、参数来源与实际参考接触条件；坡度、释放方式、初始姿态/速度、坡面与水平段尺度、观察时长 | 将一次位移当成完整摩擦检查，或据运行成功推断摩擦值正确 |

这里的“观察内容”不预设全部由程序自动识别。自动测量、人工观察和质量判断是不同的数据。用户已确认首版提前加入少量基础量化观察：摔落优先首次回弹高度（及相对释放高度比例）与最大地面穿透深度；首版不计算达到稳定所需时间。停止、持续抖动、翻滚和弹飞等过程仍由人看录像观察。具体测量口径按第 2.4.5 节逐项确认。

斜坡首版量化范围已确认：先显示沿坡位移及对应观察时长，滑动、滚动、翻倒和停止过程由录像人工观察。这是采集范围的分步安排，不缩减第 2.5 节的最终多坡度、水平滑行和跨资产比较要求。

质量与惯性等字段仍按第 1 节约定作为资产已标注输入和预检依据，不因为结果页需要上下文就新增独立质量、质心或惯量标定试验。浸水测试继续后置。

#### 2.4.3 结果表达与验收要求

- 分开呈现资产能否运行、程序是否执行完成、观察到了什么，以及人如何解释这些现象。运行失败不能标为资产物理不合格，运行成功也不能标为资产物理合格。
- 未运行、未记录、未测量、尚未人工检查和不适用须按实际情况区分；缺失值不能显示为零、正常或已通过。人工意见的保存方式尚未决定，不擅自给只读页面增加写入功能。
- 观察期内没有停止，只能说明该时窗内未观察到停止；录像结束或数值有限不能替代稳定性判断。当前 1 秒功能片段不能被描述成已经完成完整停止过程检查。
- 待检查参数仍保留准确字段名与值，并配中文解释。中文简化不能删除组合参数、来源或参考接触条件，否则无法知道录像是在检查什么。
- 净空须解释为最低碰撞点距参考面的距离，并与质心高度区分；同时保留相对资产尺度的高度档位。物理模拟时长与含片头静止展示的视频时长分开。
- 不从未经采集的数据生成回弹高度、穿透深度、停止时间或“过滑/过黏”结论。若后续增加测量，必须先定义测量对象、坐标基准、单位、采样方式和未完成观察的处理规则。
- 场景中的尺寸参考物和高度标记属于原方案需求，不能用视频旁边的一行高度文字代替。录像应覆盖所需的碰撞、运动和停止观察；仅“文件可播放”不满足物理检查需求。
- 首版仍不自动给出通过/不通过、质量评分或资产排名，不根据录像反推参数现实真值，也不自动调参。

### 2.5 最终交付与验收标准

**最终交付是：检查者能够对一个确定版本的完整 USD 资产，在统一的摔落、斜坡与水平滑行条件下，依据参数、量化观察和可比较的录像，判断其内部物理合理性，并追溯判断依据。**下面验收的是系统能否提供可信的检查材料，不要求每个被测资产都表现正常，也不证明参数等于现实真值。

量化验收要求明确首次回弹的事件起止与离地容差、穿透的几何定义及统计时窗、沿坡位移采用的测量点/方向/起止时刻，以及各量的精度目标和采样验证方法。本地 v1 定义与初步对照已记录于数据约定，仍须补齐真实 GPU 采样和步长误差证据才能关闭 F06。多刚体摔落须测整体；斜坡当前单刚体定义不能直接扩展为取多刚体中的一个代表整体，位移不得与累计路程混称。不以未经确认的数值阈值填充物理合格标准。

验收证据应包含正常案例、已知异常或对照案例、缺失/失败及观察时窗不足的案例，用于核查系统是否准确呈现事实。测试样例和预期结果须明确标记，不冒充真实资产实验；沿用已有有效证据，仅对新功能、变化与未验证部分增加检查。异常资产被正确展示仍可证明系统有效，不能为了“通过验收”修改资产参数让其表现正常。

#### 2.5.3 完成判定与范围边界

每项 F01–F08 的验收记录必须注明实现版本、案例/工况、执行日期、原始证据位置、实际结果和剩余缺口。未完成项不能用“已规划”“有字段”或“录像能播放”关闭；文档本身不构成验收通过证据。已入库但缺少斜坡参数的资产，应显示斜坡未就绪，不能当作系统已完成斜坡验收的样本。

本项目当前约定的完整交付仍以人工判断为核心：不把自动质量评分、排名、停止时间量化或滑动/滚动自动分类追加成最终必达项。浸水、真实材料参数标定和自动调参继续后置；批量资产提交、Web 管理也不能与人工多工况比较混为一谈。人工检查意见是否在页面持久保存仍待确认，当前只读结果页不因本节自动获得写入范围。

## 3\. 摩擦数值的限制与研究方向

### 3\.1 当前方案的限制

现实中的滑动和滚动摩擦都取决于两个接触表面，以及粗糙度、载荷、速度、温度、磨损和润滑状态。MuJoCo 必须从两个碰撞体的字段得到一个最终值；同优先级时通常取两侧摩擦参数中较大的值。这是仿真计算规则，不是现实材料定律。

因此，本方案中的摩擦试验只能用于：

- 发现资产默认摩擦值导致的明显过滑、过黏或滚动异常；
- 为人工检查提供统一、直观的比较场景；
- 作为没有更具体接触数据时的粗略检查。

它不能用于：

- 推断资产与所有其他材料接触时的真实摩擦；
- 精确预测不同材质夹爪所需的夹持力；
- 替代真实材料接触试验。

### 3\.2 相关论文

- [Generalizable Friction Coefficient Estimation via Material Embedding and Proxy Interaction Modeling](https://arxiv.org/abs/2604.24188)：最直接针对任意材料组合问题。它让每种材料只与少量代理材料进行测试，再学习预测任意两种材料的摩擦，将测试数量从两两组合降低为与材料数量近似线性增长。目前是 2026 年 arXiv 预印本，仍需要代理材料测量和模型训练，适合作为后续研究方向。
- [Probabilistic Surface Friction Estimation Based on Visual and Haptic Measurements](https://arxiv.org/abs/2010.08277)：结合视觉和少量机器人触觉探索，估计多材料物体表面的摩擦分布。它可以减少逐点测试，但仍需要真实接触数据。
- [In-Hand Object-Dynamics Inference using Tactile Fingertips](https://arxiv.org/abs/2003.13165)：让机器人逐渐减小夹持力直到发生滑移，通过触觉测量估计夹爪与物体之间的实际摩擦，适合后续抓取场景。
- [Online Friction Coefficient Identification for Legged Robots on Slippery Terrain Using Smoothed Contact Gradients](https://arxiv.org/abs/2502.16843)：根据机器人运动和接触结果在线反推当前接触的摩擦系数，说明摩擦可以在实际交互中识别，而不必完全依赖资产预标注。
- [Friction from Vision](https://www.martimbrandao.com/papers/Brandao2016-humanoids-friction.pdf)：研究根据图像、材质类别和文字资料预测机器人接触摩擦，同时表明仅凭人眼判断摩擦存在明显不确定性。

当前报告不采用上述复杂方法，只保留“资产默认摩擦值的直观筛查”。如果未来需要提高夹爪接触精度，可以优先研究代理材料方法或基于滑移的在线识别。
