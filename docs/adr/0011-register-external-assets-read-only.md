# 原位登记外部只读 USD，输出仍归个人数据根

公共区域的资产可能由其他人维护，重复复制耗费空间；本程序也不应移动、改变权限或在其目录写产物。新增独立的外部登记流程，保留既有 inbox 原子入库流程。登记仅写 `asset-references` 元数据与验收报告，允许指定包内任意 USD 入口，解析并哈希全部依赖，使用相同物理预检规则。登记未就绪资产不会授予运行资格。

外部身份绑定来源目录、入口和来源名称；不与入库身份混用。版本同时绑定入口和依赖内容，运行准备、加载前后及结束复核内容与文件状态，变化时拒绝或失败，禁止静默改用最新内容。运行 manifest 保存来源及复核证据，结果摘要不暴露额外公共文件服务。任务中公共源目录单独只读挂载，结果和缓存置于个人目录或任务临时目录。

登记指纹不是本程序保存的不可变资产副本：所有者仍可能更改或删除内容，有限检查点不能冻结文件，也不能保证长期复现。长期保存仍使用入库模式或来源方的稳定版本目录。该决定扩展 ADR 0005 的存储方式，不改变 GPU 执行策略、物理参数规则或正式 profile 的未开放状态。详细操作与限制见[外部只读资产](../外部只读资产.md)。
