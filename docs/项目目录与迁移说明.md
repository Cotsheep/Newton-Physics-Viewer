本轮整理日期：2026-10-06。日常查看服务器结果只需双击项目根目录的
`open-server-results.cmd`；它读取本机个人配置中的 SSH 别名和端口。

`.venv`、`.git`、编辑器配置和已有缓存保留。两个 Python 包及根目录的三个
兼容 Python 入口保持名称和位置，避免改变导入、个人环境的可编辑安装和业务行为。

## 迁移对照

| 原位置 | 新位置 | 处理方式 |
| --- | --- | --- |
| `deployment/local/open-server-results.cmd` | 根目录 `open-server-results.cmd` | 正式入口；从任意工作目录定位项目，读取个人配置 |
| `record_collision_comparisons.py` | `tools/record_collision_comparisons.py` | 修复项目导入路径，更新使用命令 |
| `VIEW_USAGE.md` | `docs/VIEW_USAGE.md` | 更新链接及打包清单 |
| `deployment/*.yaml` | `deployment/templates/` | 模板内容原样保留，修复文档和测试引用 |
| 部署、录像、测量及协作指南 | `deployment/guides/` | 修复相对文档链接 |
| `ACCEPTANCE_RUN_2026-09-13.md`、`LOCAL_VALIDATION.md` | `deployment/history/` | 保留历史事实和原始路径，只修复导航链接 |
| local 当前两份笔记 | `deployment/local/notes/` | 分开保留进展与环境问题；添加当前导航 |
| local YAML、辅助脚本、报告与日志 | `configs/`、`tools/`、`evidence/`、`sessions/` | 按用途分类，修复工具的实际读写路径 |
| local 旧交接、旧提交清单和旧目录迁移脚本 | `deployment/local/archive/` | 保留并标记历史用途 |

个人迁移记录位于 `deployment/local/archive/directory-migration-20261006/`，
记录迁移前的路径、大小、SHA-256 和迁移目标；被修改的个人原件另存于
`originals/`。历史输出中的 commit、hash、时间及内嵌原始路径不批量替换。
上传包和证据目录内的原始材料不改内容。Git 保存受跟踪文件的旧版。

## 服务器边界

服务器个人项目继续采用 `projects/newton-test/`。HOME 下的 `repo/` 通过
Git 更新，`releases/` 保存不可变源码导出，`configs/` 保存个人配置，
`env/` 保存结果服务环境，`archive/` 保存历史证据。共享项目中的 `data/`、
`sources/`、`env/`、`graphics/` 保持既有路径，不重新复制或安装。

真实服务器路径、SSH 别名与身份信息只写个人资料或个人配置。Windows 的
`deployment/local/` 不整目录覆盖到 Linux；服务器只补充适合自身的索引。
本轮不运行 GPU、修改公共资产或重写既有导出。正式 profile 仍为
`reserved_not_runnable`。
