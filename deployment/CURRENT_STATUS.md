## 环境问题与解决方式

任务容器曾只得到 `compute,utility`，尽管 experiment 配置中写了 `graphics`；诊断同时显示 NVIDIA EGL 库加载失败、标准 vendor 目录只有 Mesa。解决方式是预先下载匹配节点驱动的官方用户态图形包，校验后解包到独立共享目录，再在单个任务中只读挂载并显式设置库搜索路径和 EGL vendor 文件。没有安装或更换系统驱动，也没有修改共享 Python 环境。

解包只做一次，同版本任务复用该目录；每次任务先核对实际节点驱动，再设置加载路径。此兼容方式按驱动版本和运行环境适配，不按资源池名称适配。`mktemp -d` 的 700 权限曾阻止挂载，定位后只把顶层图形目录改为 755。原数据、环境、导出和下载包均保留。

操作细节见 [GPU 录像说明](GPU_VIDEO_SMOKE.md)、[部署说明](README.md)；真实地址、路径和软件包校验值只放在被 Git 忽略的 `deployment/local/环境配置与问题记录.md`。运行编号和原始证据索引由本地交接资料保存，不把环境笔记写成实验结果报告。
